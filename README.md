# CREASE & COLLAR INDIA ✦
### Luxury Bespoke Shirts & Tailored Trousers Showroom Studio

An exclusive, high-fashion menswear digital showroom dedicated purely to fine shirts and tailored trousers (Pant-Shirt only, zero coats/suits), crafted for the Indian market.

---

## ✨ Key Features

- **Exclusive Pent & Shirt Focus**: Hand-cut single-needle 24-SPI Egyptian Giza cotton shirts paired with knife-creased pleated Gurkha trousers.
- **Interactive Macro Zoom Studio**: Header section with multi-level zoom (1.0x, 1.8x, 2.6x), 2.8x cursor magnifier loupe, and interactive garment hotspot pins.
- **Curated Silhouette Switcher**: Switch between signature looks with live macro fabric previews and technical specifications.
- **Pair Studio Matchmaker**: Interactive real-time ensemble builder pairing shirts and trousers with dynamic price calculation.
- **India-Exclusive Experience**:
  - All pricing in Indian Rupees (`₹ INR`) with Indian numerical formatting.
  - Flagship fitting studios in **Mumbai (Kala Ghoda)**, **New Delhi (The Chanakya)**, **Bengaluru (Lavelle Road)**, and **Hyderabad (Jubilee Hills)**.
  - Integrated showroom booking modal with WhatsApp/phone appointment confirmation.
  - Pan-India insured delivery & GST invoicing support.
- **Luxury Light Aesthetic**: Crisp `#FAF8F5` showroom ambiance, refined serif typography, and featherlight navigation.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **UI / Styling**: React 18, Tailwind CSS
- **Animations**: Framer Motion, Lenis Smooth Scroll, Canvas Confetti
- **Icons**: Lucide React
- **Language**: TypeScript

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
